📘 สรุปการทำงานของ Socket.IO

  • 🔹 socket.emit('event', data): ส่งข้อมูลไประบุชื่อ Event และ Data
  • 🔹 socket.on('event', callback): รอรับฟัง เมื่อมีสัญญาณ Event ตรงกันจะทำงาน
  • 🔸 socket.emit(...): ส่งกลับหาคนส่งคนเดียว (Only Me)
  • 🔸 socket.broadcast.emit(...): ส่งหาทุกคน ยกเว้น ตัวเอง (Broadcast)
  • 🔸 io.emit(...): ส่งหาทุกคนในระบบ รวมทั้ง ตัวเอง (To All)
  • 🔸 io.to('room-id').emit(...): ส่งหาเฉพาะคนที่อยู่ในห้องนั้นๆ (To Room)

✉️ กล่องทดสอบส่งข้อมูล
